# Trash Match Live

Quiz en direct sur le tri des déchets, façon appli de rencontre : chaque déchet cherche sa poubelle idéale.

- **Grand écran** : ouvrir la page et cliquer « Je présente sur le grand écran ». Un QR code et un code à 4 chiffres s'affichent.
- **Joueurs** : scanner le QR code avec leur téléphone, choisir un pseudo, répondre. Aucun compte nécessaire.

21 questions en 5 manches, classement en direct. Connexion entre appareils via PeerJS.
